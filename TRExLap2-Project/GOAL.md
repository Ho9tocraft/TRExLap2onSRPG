# GOAL
## 目的
1. 画像(透過PNG, RGBA8)の読み込みと、それをVulkanレンダリングするまでの実装。
  - 追補1: これから先、tomlロードによって画像がコロコロ変わることを想定して、「画像ファイルから解像度を取得」し、それを元に、その画像の「解像度通りの表示」を実行するようにする。
2. NVIDIA DLSSによるDLAAレンダリング。
3. 音声再生。
  - 追補1: OGG形式のループタグ付きBGMを、同様に再生できるか確認する。
  - 追補2: ループタグ付きBGMがループするときのノイズをなくすためのギャップレス化(必須だが、現段階では保留)。
4. (Optional)ハイ・ダイナミックレンジ(HDR)レンダリング。オマケなので、やらなくても問題はない。
※第3段階まで実装後、再び草案考案フェーズを開始する。移動先のin-draftフォルダにて、md形式でメモを取る。

## 成果物
- Debug x64を実行可能なソースコード。
